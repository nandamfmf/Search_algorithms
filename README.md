# Search Algorithms

This repository contains implementations of search algorithms in C++, developed as part of my Computer Science studies at the Federal University of Rio Grande do Norte (UFRN).
The project focuses on understanding how different search algorithms work, implementing them from scratch, and comparing their approaches to finding elements in a collection of data.

## About the Project

The goal of this project is to study and implement search algorithms while exploring their differences in terms of logic, performance, and complexity.
Each implementation provides an opportunity to understand how the algorithm works and how its characteristics affect the search process.

## Technologies

- C++
- CMake
- Git

## Learning Goals

- Understand the logic behind different search algorithms.
- Implement algorithms in C++.
- Analyze time and space complexity.
- Practice code organization and testing.
- Compare different approaches to solving the same problem.
